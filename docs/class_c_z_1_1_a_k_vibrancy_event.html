Detailed Description

Notifies nodes that the vibrancy (background blur) state changed.

Sent to a node tree when vibrancy becomes enabled or disabled, e.g. by Marco's MSurface when the compositor confirms or revokes background blur support, so nodes such as MVibrancyView can switch between vibrant and opaque styling.
