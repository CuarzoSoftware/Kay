Detailed Description

Renders a tree of nodes into AKTargets.

A scene calculates the layout of its node tree, tracks damage and renders the nodes back-to-front into a given target during render(). It also behaves like a window from the input point of view: it keeps the pointer and keyboard focus and dispatches input events to the right nodes (see Event System).

Applications typically use one scene with a single target per window, while compositors can share one scene across multiple targets (e.g. one per screen). See Core Components.
