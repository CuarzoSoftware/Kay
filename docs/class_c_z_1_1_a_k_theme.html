Detailed Description

Centralized visual style for built-in components.

AKTheme gathers everything Kay's built-in components use to draw themselves:

  • Colors: adaptive (light, dark) macOS-style system colors as CZAdaptiveColor static members, plus a few Cuarzo-specific ones.
  • Fonts: the default Skia font and text styles (initialized in the constructor, using the "Inter" family).
  • Metrics: per-component constants such as paddings, radii and scroll physics.
  • Baked assets: lazily created, per-scale cached images (nine/three-patches, shadows, window buttons, masks) exposed through virtual factory methods and CZAssetManager members.

The active theme is returned by CZ::theme(), which lazily creates the default one. To customize the look, subclass AKTheme (e.g. overriding the virtual asset factories or adjusting the static members) and install it with CZ::setTheme().
