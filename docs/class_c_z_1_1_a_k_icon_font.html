Detailed Description

A utility class for rendering and caching icons from an icon font.

This class allows loading icons by name or codepoint from a font family and renders them as images. It also handles caching and efficient retrieval of icons.

Creates an icon font from a font family and an optional codepoint map.

This method loads an icon font based on the specified font family. Optionally, it can load a codepoint map from a file. If the codepoint map fails to load, or the font is not found, the icon font is still created with a fallback font.

Use hasCodepointMap() to check if the map was successfully loaded.

Parameters
fontFamilyThe name of the font family.
codepointsPathPath to a .codepoints file containing icon name and hex codepoint pairs.
Returns
A shared pointer to an AKIconFont instance, or nullptr on failure.
