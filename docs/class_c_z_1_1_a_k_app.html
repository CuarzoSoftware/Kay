Detailed Description

Core application class.

A per-process singleton providing shared services to all scenes: input state and focus (pointer(), keyboard()), font services and access to the CZCore (event loop) and RCore (Ream graphics) instances. Input events are typically sent to the AKApp, which dispatches them to the focused AKScene (see Event System).

std::shared_ptr< AKApp > GetOrMake ( )
staticnoexcept

Returns the current AKApp instance, or creates one if none exists.

Kay requires both a CZCore and an RCore instance to function. The CZCore instance handles Kay's event loop source, which is dispatched via CZCore::dispatch(). If you are not using Louvre or Marco, you must create both CZCore and RCore instances manually before calling this, otherwise, nullptr will be returned.

Returns
A shared pointer to the AKApp, or nullptr on failure.
