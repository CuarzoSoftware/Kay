◆ hasPointerFocus()

bool hasPointerFocus ( ) const
noexcept

Checks whether this node currently has pointer focus.

Pointer focus is assigned by the parent scene when handling pointer events to the first node whose input region intersects the pointer position. The node with direct focus can be queried via scene()->pointerFocus().

Focus is also propagated upward through the parent hierarchy. Therefore, this method may return true even if:

  • this != scene()->pointerFocus()
  • isPointerOver() returns false.
