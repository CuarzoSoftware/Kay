Detailed Description

Global keyboard state.

Owned by AKApp (see AKApp::keyboard() or the CZ::akKeyboard() shortcut), it keeps the most recent keyboard events dispatched by Kay and the scene currently holding keyboard focus. AKApp forwards keyboard events to the focused scene, which then dispatches them to its focused nodes.
