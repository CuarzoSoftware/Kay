Detailed Description

Global pointer state.

Owned by AKApp (see AKApp::pointer() or the CZ::akPointer() shortcut), it keeps the most recent pointer events dispatched by Kay, the current cursor position and the scene currently holding pointer focus.

AKScene * focus ( ) const

Returns the scene currently holding pointer focus.

Note
In the context of Marco, a scene can be thought of as a window.

This represents the last scene that received a CZPointerEnterEvent. Scenes that are not focused will ignore pointer events. Each scene provides information about its focused nodes.
