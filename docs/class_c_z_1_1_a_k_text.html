Constructs the node with the given UTF-8 text.

Uses the theme's default text style and AKTheme::Text as glyph color. The input region is empty by default, so the node ignores pointer events.

Glyph color, as a CZAdaptiveColor (distinct light/dark, resolved for the current color scheme and re-resolved automatically when it changes).

Note
Named setTextColor (not setColor) to avoid colliding with the node-level AKRenderable::setColor(), which — with enableReplaceImageColor — is a separate, lower-level recoloring of the baked image (e.g. how AKButton tints its label).
